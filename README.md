# Calcolatore Canone Concordato Messina 2024

🌐 **[👉 CLICCA QUI PER USARE IL CALCOLATORE ONLINE 👈](https://smn-frd.github.io/Calcolatore-Affitto-Concordato-Messina-2024-2026/)**

Questo è un calcolatore online basato sull'**Accordo Territoriale del Comune di Messina 2024**. Lo strumento è progettato per aiutare proprietari e inquilini a farsi un'idea del valore del canone con cui si può affittare un immobile seguendo le regole del canone concordato.

## 🚀 Funzionalità
- Calcolo automatico della superficie convenzionale (Allegato C).
- Selezione dinamica delle microzone (Allegato A).
- Applicazione degli incrementi basati sulle caratteristiche dell'alloggio (Allegato B).
- Supporto per contratti agevolati (3+2), transitori ordinari e transitori per studenti.
- Opzione per affitto parziale (stanze).
- Calcolo della forbice di trattativa (±10%).

## ⚠️ Disclaimer Legale (IMPORTANTE)
**L'autore di questo software non si assume alcuna responsabilità legale.**

Sebbene i calcoli siano implementati seguendo fedelmente i parametri tecnici dell'accordo del 2024, questo strumento **NON ha validità legale**.
- I risultati sono da considerarsi puramente indicativi ("un aiuto per capire prima").
- Per ottenere un'attestazione valida ai fini delle agevolazioni fiscali (IMU ridotta, Cedolare Secca al 10%, etc.), **è necessario rivolgersi alle organizzazioni sindacali firmatarie, come la SICET**, per la verifica e il rilascio della documentazione ufficiale.

## 🛠️ Sviluppo e Build
Il progetto è diviso in componenti modulari in `src/`. Per generare il file `main.html` finale:
1. Assicurati di avere Python installato.
2. Esegui:
   ```bash
   python3 build.py
   ```
